# Personal Environments

This configuration covers personal macOS workstations and user environments on
Linux development servers.

## Language

**Shared CLI profile**:
The baseline command-line environment shared by personal macOS workstations and
Linux development servers.

**Darwin home profile**:
The personal macOS user environment, including desktop applications, language
tools, and personal SSH agent integration.

**Darwin role**:
A macOS workstation category, currently laptop or desktop, that determines
machine-specific application choices.

**Darwin system profile**:
The personal macOS system environment, including workstation preferences,
system services, and application installation policy.

**Linux home profile**:
The lab user's command-line environment on a development server whose system
installation and daemon remain administrator-owned.

**Nix language tools**:
Tools for editing and formatting Nix expressions, distinct from the Nix or Lix
package manager implementation.
