# Starship Module

English | [简体中文](README.zh-CN.md)

This module configures the Starship prompt.

## Maintenance

The `plain-text-symbols.toml` file is generated using the Starship preset command.
To update it after a Starship upgrade, run from the repository root:

```bash
starship preset plain-text-symbols > modules/starship/plain-text-symbols.toml
```
